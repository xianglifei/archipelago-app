群岛不用你配 API Key、也不用选模型。居民统一走**群岛通道**,按积分计费。界面里只有「快速」一档,厂商与模型版本不出现——这是刻意的:你不需要为选型负责。

## 积分从哪来

- **注册登录即送 500 积分**,有效期 **30 天**。
- **兑换码**充值;活动期会发**活动码**,一码可多席。
- 余额不足时不能靠「先欠着」继续跑——服务端会兜底拦截。

## 怎么扣

| 行为 | 扣费 |
| --- | --- |
| 居民对话(单聊 / 群聊 / 任务会话) | 按 token 用量折算积分 |
| 定时任务回合 | 同对话 |
| `web_search` 联网搜索 | **1 积分 / 次**(有结果才扣;失败自动改用本地搜索且**不扣**) |
| `web_fetch` 抓网页 | 本机为主,**不扣**;网络类失败自动云端兜底时 **1 积分 / 次** |
| 邮局收发信件 | **免费** |
| 居民之间的私信 | 按回合计费(和对话同口径) |

几条口径:

- **批次先到期先扣**:你有多批积分时,先过期的先花掉。
- **失败不扣**:模型请求失败、零输出的重试,上游不扣费;重试不产生双扣。
- **图片与附件**:图片会先缩放再内联给多模态模型,历史图片只保留岛内副本与缩略图,不重复占用上下文——这也是在替你省积分。

## 在哪看

**设置 → 套餐与积分**:

- 余额与到期时间;
- **近 7 天消耗**柱状图:从首个有消耗的那天起显示,最右固定今天;
- 获取记录:只列入账,不与扣费混在一起。

## 余额预警

- **低于 200 积分**:输入框上方亮预警条。
- **用完**:提示充值并**暂停发送**。服务端 403 是最终兜底——即使界面状态错乱,也不会让你透支。

## 兑换与充值

- 兑换码在「套餐与积分」页输入。入账失败不会吞码,可重试。
- 活动码一码多席,同一个码可以给多人用。
- 兑换与消费都有幂等保护:极端故障下不会重复扣款,也不会双倍入账。

## 省积分的几个习惯

1. **别让居民在长会话里反复重述背景**——上下文越长,每回合越贵。长活拆成任务会话,上下文从零开始。
2. **长任务一口气做完更省**:单回合步数上限已放宽到 100,中途被截停再续跑会多花一轮。
3. **搜索有代价**:`web_search` 每次 1 积分。能用已知信息回答的,别让它先搜一遍。
4. **失败的搜索不扣钱**,但多次失败会拖长回合。重复失败时看[常见问题](/docs/help/faq)。

## 常见疑问

**换了电脑,积分还在吗?**
在。积分挂在账号上,不在设备上。但岛本身不跨设备,见[登录与账号](/docs/getting-started/account#岛--账号--设备)。

**30 天到期是硬过期吗?**
送的 500 积分有效期 30 天,过期作废。兑换来的积分按各自批次的有效期计算,同样「先到期先扣」。

**居民说余额不足,但图表看着还有?**
以「套餐与积分」页的余额为准;预警条与服务端 403 都以同一份余额判断。若两者长期不一致,走反馈渠道报 bug。
