## 技能卡是什么

一张**技能卡**就是一套可复用的做法:一段正文(步骤、判断标准、注意事项),加上可选的随卡文件(脚本、模板)。居民学会之后,遇到同类的事就按卡里的做法办。

技能卡不是插件,也不是提示词收藏。它有三条明确的规矩:

1. **正文原样保留**,不会被压缩改写;
2. **只有创建者能改**,别人只能学或卸;
3. **改动有版本留档**,已学会的居民下一回合起自动用新版。

## 三种来源

| 来源 | 谁做 | 怎么进来 |
| --- | --- | --- |
| 居民自建 | 岛上的居民 | 对话里说「把刚才这套做法记成技能卡」,TA 调 `create_skill` |
| 岛上互学 | 岛上其他居民 | 居民调 `install_skill`(可跨居民学,前提是你造的卡或公开卡) |
| 岛主导入 | **你** | 把技能包拖进聊天,或放进 `~/群岛/技能收件箱/`,再让居民导入 |

自建与学习都会弹审批卡:创建时卡上能看到整张卡;**学习时卡上带正文预览**——先看清楚再点允许。

## 技能中心

导航栏第三格是技能中心,两个 Tab:

### 精选推荐

云端目录的分类货架。点开能看技能详情与出处链接,点「安装」就复制进你的岛。此后它和自建卡同等待遇。

云端下架或删除**不影响已安装的用户**——你岛上那份是你的。

### 岛上的技能

全岛清单,展开能看正文、版本历史、安装名单。操作有三个:

- **安装到指定居民**;
- **冻结**:全岛停用,卡还在,只是没人用;
- **删除**:软删除 + 全岛卸下。

居民档案的「技能」页签里则只做一件事:**卸下**。一键即卸,不二次确认——卡还在技能中心,随时能再装。

## 上限与名册模式

这些数字是硬上限,写卡前先记住:

| 项 | 上限 |
| --- | --- |
| 技能名(自建 / 互学) | 20 字 |
| 描述(自建 / 互学) | 120 字 |
| 单卡正文(自建 / 互学) | 10,000 字 |
| 导入技能包的名字 / 描述 | 64 / 500 字(正文不设限) |
| 常驻注入「你的技能」节的全文总量 | 8,000 字 |
| 可学手艺名册 | 10 行 |
| 已装技能名册 | 30 行 |
| 单居民同时装卡数 | 不设上限 |

**装多了会怎样?** 已学会的卡,正文会全文注入居民上下文——但总量超过 8,000 字时自动切成**名册模式**:一行一卡,只列名字和描述。居民真要用某张卡时,再调 `load_skill` 把全文取回来。

这意味着:装几十张卡不会把上下文撑爆,但也不代表每张卡都在「常驻记忆」里。真正高频的卡,保持短小才划算。

## 导入别人做的技能包

支持 **Claude Code 同款文件夹形态**:一个文件夹,里面有 `SKILL.md` 加脚本、模板等随卡文件。

### 两个来源,别的地方一律不收

1. 你在聊天里**直接发给居民的附件**;
2. 主目录「群岛」文件夹旁的 **`~/群岛/技能收件箱/`**。

居民**不会**去磁盘上随便读一个路径——这是刻意的来源锁死,防止某个技能包诱导它读你的私密目录。

### 导入会发生什么

```
把技能包拖进聊天(或放进技能收件箱)
  → 跟居民说「记成技能」
  → 半自动档:审批卡上先给你看整张卡 + 随卡文件清单(含来源路径)
  → 允许 → 落成技能卡
```

- **卡正文原样保留**,再长也不压缩(仍受 10,000 字上限)。
- 随卡文件原样布局进每位学会居民的**工作区 `技能/<卡名>/`** 里,卡里写的相对路径(如 `scripts/run.py`)照常可用。
- 执行命令仍按该居民自己的权限档位走审批。
- 技能中心与档案里会标**「岛主导入」**;导入的卡居民改不了,要更新就删掉重新导入。

### 会失败的情况

- 文件夹里没有 `SKILL.md`;
- 单文件导入但不是 `.md`;
- 正文为空;
- 岛上已有**同名**技能(请先删旧的,或换个名字重导);
- 工作区里已有同名目录但不是这张卡(比如居民自建)——拒绝合并覆盖,不会动你原来的东西。

删除导入卡时,各居民工作区里的随卡副本会一并清掉。

## 服务能力卡(MCP)

精选推荐里还有一类**服务能力**卡,外形和技能卡一样,装上后居民能直接调用外部服务(首批:高德地图、滴滴出行、麦当劳)。

- 安装时自然地问一次密钥;
- 每次调用都过**同一道审批门**(半自动弹卡,全自动留痕);
- 单居民工具预算 24k 字符,结果超长会截断;
- 401 / 429 / 超时都有说人话的错误;
- **只有岛主能装**,居民侧没有安装通道;不提供手动添加自定义服务的入口。
