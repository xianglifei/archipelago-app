群岛(Archipelago)是一支住在你 Mac 里的 AI 团队:居民各有分工、互相协作,共用你这台电脑,数据全部留在本机。它不是聊天壳子——居民能读写文件、跑命令、联网查资料、按时间表办事,所以「谁批准了什么、产物放在哪」必须有权威答案。

这份文档讲三件事:新用户怎么从下载走到第一个任务;权限、审批、任务会话这些高风险机制怎么运作;以及想改代码或写技能卡的开发者需要知道什么。

## 术语先行

群岛的界面词有自己的一套。看完这张表,后面的页面会好读很多。

| 词 | 指的是 |
| --- | --- |
| **岛** | 一座岛 = 一个账号 × 一台设备。换设备、换账号就是另一座岛,数据不互通、不同步 |
| **岛主** | 你。唯一的权限持有者,也是所有审批的最终决策人 |
| **居民** | 岛上的 AI Bot,有自己的名字、角色、性格、记忆、技能与工作区 |
| **工作区** | 每位居民的一个真实目录(默认在 `~/群岛/` 下),居民的读写与命令默认落在这里 |
| **审批卡** | 半自动档下,居民做危险操作或越界写入时,把输入行换成决策面板的那张卡 |
| **定时任务** | 居民按时间表自主办事(「每天早上汇总新闻」)。入口在居民档案的「定时」页签 |
| **任务会话** | 给某位居民开的一个上下文隔离的专属会话,一件事一个空间。消息列表里的「新建任务」指这个 |
| **技能卡** | 一套可复用的做法。居民可自建、互学,也可由岛主导入技能包 |
| **岛主档案** | 全岛居民共同维护的关于你的画像,新居民入住第一天就懂你 |

<Callout type="warn" title="「任务」这个词有两个意思">
界面上的「新建任务」「任务会话」= 上下文隔离的会话;而定时任务住在居民档案的「定时」页签里。
**这份文档为了不歧义,一律写全称:任务会话 / 定时任务**,不单用「任务」二字。如果你在别处看到口径不一致,以界面上的「定时 / 新建任务」两个位置为准。
</Callout>

## 版本与维护承诺

- 每页页脚都标了**适用版本**与**最后更新**。群岛发版很快,机制改了我们同步改页面;页脚日期太久没动的页面,先当作可能过时。
- 文档只写**已发版**的功能。看到了但你没装到对应版本,先升级客户端。
- 中文首发。英文只做核心页,暂不在计划内。
- 文档源码在本仓 `docs/` 目录,每页右上角有「编辑此页」。改文档的 PR 会自动跑构建预览,合并到 `main` 后自动部署到 `docs.qundao.app`。
