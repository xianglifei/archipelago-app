## 系统要求

| 平台 | 要求 | 安装包 |
| --- | --- | --- |
| macOS | **Apple Silicon(M 系列)**,暂不提供 Intel 版本 | `Archipelago-<版本>-arm64.dmg` |
| Windows | **Windows 10 / 11,x64** | `.exe`(NSIS 安装器) |

群岛是 Electron 桌面应用,装完约几百 MB。它需要联网:登录、居民对话、云端搜索都要走群岛通道。

## 下载与安装

统一从官网下载页拿最新正式版:

**[qundao.app/download](https://qundao.app/download)**

- macOS:打开 DMG,把群岛拖进「应用程序」。首次启动若被系统拦下,到「系统设置 → 隐私与安全性」允许一次即可。
- Windows:运行安装器,按提示完成。首次启动 SmartScreen 可能提示「未知发布者」,选择「更多信息 → 仍要运行」。

<Callout type="info" title="别从第三方站下载">
官网和 GitHub Release 是唯一发布渠道。第三方站的安装包可能被改动,而群岛会拿到你的本机文件与终端权限。
</Callout>

## 更新

### macOS:原地更新

- 启动后自动检查一次,之后**每 6 小时**后台检查;睡眠唤醒、断网恢复会自动补查。
- 也可以在**设置 → 关于**里手动检查。
- 新版就绪后点「重启并更新」,后台已经下载好并做过 sha512 校验,一键完成替换。即使你直接退出应用,下次启动前也会装好。
- 第二次起的更新会尽量走**增量下载**(差分缓存),不必每次拉全量。
- 原地更新不可用或失败时,会自动退回「下载 DMG + 手动拖装」,不会把应用卡在半更新状态。

### Windows:目前需要手动更新

Windows 版暂未接入应用内更新器,应用里会明确显示「不支持」。发新版后请回到[下载页](https://qundao.app/download)重新安装覆盖,数据与工作区不受影响。Windows 的发版频率也比 macOS 低。

### 灰度与最低版本

部分版本按机器稳定哈希**分批灰度推送**,同一版本你可能比朋友晚一两天收到,这是正常的。低于某个最低版本的客户端会被强制升级提示——老版本可能已经和后端协议对不上。

## 你的数据在哪

三处,互相独立:

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 工作区(居民干活的目录) | `~/群岛/`(macOS 与 Windows 均为用户主目录下) | Finder / 资源管理器里直接可见。每位居民一个子目录,如 `~/群岛/Momo-a1b2c3` |
| 应用数据(数据库、日志、更新缓存) | 系统的应用数据目录 | macOS 在 `~/Library/Application Support/` 下以应用名命名的目录;Windows 在 `%APPDATA%` 下同名目录。**不在工作区里** |
| 导出产物 | 你选的位置 | 对话导出 Markdown、保存的图片等,走系统保存对话框 |

- **升级不会动这两处。** 卸载应用默认也**不会删除** `~/群岛/` 和应用数据目录。
- 岛与岛之间物理隔离:同一台设备不同账号的数据在各自账号目录下,不共享。
- 居民、记忆与工作区文件**只存在本机**,服务端不保存一份、也没有跨设备同步。哪些内容会发给模型或云端服务,见[权限与审批](/docs/concepts/permissions#哪些数据会离开本机)。

## 卸载

- macOS:把群岛从「应用程序」拖进废纸篓。
- Windows:设置 → 应用 → 卸载。

想彻底清干净,再手动删除 `~/群岛/` 与应用数据目录。**这一步不可恢复**,删之前先确认工作区里没有你要留的文件。
