假设你已经[安装好](/docs/getting-started/install)并[登录](/docs/getting-started/account)了。下面这条路大约五分钟。

## 第 1 步:完成开场向导

向导只有三步:

1. **给岛起个名字**(会给随机建议,不满意可以自己改);
2. **怎么称呼你**(岛主称呼,之后居民会这么叫你);
3. 完成。

完成页上,Momo 会先入住打招呼。Momo 的角色是「岛务长」,负责调度全岛。同时 **500 积分自动到账**(30 天有效),够你用一阵子。

## 第 2 步:认识主界面

- **最左侧 84px 窄导航栏**:消息 / 邮局 / 技能中心 / 设置。
- **消息列表**:单聊与群聊混排,按最后一条消息时间排序。
- **聊天区**:右边是当前会话。居民干活时,一轮的思考与工具调用会折叠成一粒「已工作 N 秒 · M 个动作」小签,点开能看完整时间线。

## 第 3 步:邀请第二位居民

只有 Momo 一个不够热闹。点消息列表上方的「＋」→「新建居民」:

- **名字**:可以点骰子从名字库里随机;
- **角色标签**:一句话说明 TA 负责什么,比如「文案」「用户增长」「测试」;
- **头像**:28 种造型 × 12 款眼睛实时拼合;
- **性格**:八型原型(元气 / 温柔 / 悠闲 / 知性 / 大姐 / 行动派 / 风雅 / 小太阳),默认「温柔」。

<Callout type="tip" title="人设可以先留空">
不用一开始就写一大段人设。居民会在对话里自我演化,也可以之后在档案里改。角色和性格才是第一天的关键。
</Callout>

## 第 4 步:交给 TA 第一件事

打开这位居民的单聊,直接说人话:

> 帮我在工作区建一个 `notes` 文件夹,写一份这周的待办清单,三条就够。

会发生什么:

1. 居民先在聊天里回一句思路,然后开始动手;
2. 聊天流里出现工具事件签(「写入 todo.md · 320 字符」这类);
3. 如果需要你批准,输入框会被换成一张**审批卡**;
4. 干完后给结果,并告诉你文件落在哪。

## 第 5 步:第一次遇到审批卡

半自动档(默认)下,居民要跑危险命令或往工作区外写文件,就会弹出审批卡。**输入行整个被替换成决策面板**,四个键直接选:

| 按键 | 含义 |
| --- | --- |
| `Esc` | 拒绝 |
| `Enter` | 允许这一次 |
| `⌘ + Enter` | 本回合不再问(回合结束后恢复) |
| `⌥ + Enter` | 以后全自动(顺手把这位居民转成全自动档,本卡放行) |

批准只对**当次**有效,而且批准的就是执行的——参数不能在批准后被改写。窗口全部关掉时一律拒绝(fail-closed)。

第一次遇到建议只按 `Enter`。等你看过[权限与审批](/docs/concepts/permissions)再决定要不要放宽。

## 第 6 步:看看产物

居民默认工作区在 `~/群岛/<居民名>-<短号>/`。打开 Finder 就能看到刚才的文件。

想换个目录?在居民档案里把工作区指到你的真实项目目录即可。任务会话还能给单个任务绑定独立工作目录,见[任务的三种形态](/docs/concepts/tasks)。

## 接下来可以试

- **让居民互相协作**:建个群,把两个人拉进来,说「讨论一下这件事怎么分工」。
- **交代一件定时任务**:「每天早上九点给我汇总一次今天的日程」。
- **把做法沉淀成技能卡**:「把你刚才这套流程记成技能卡」。
- **装一张精选技能**:技能中心 → 精选推荐。

积分怎么扣、怎么充,见[积分与计费](/docs/handbook/credits)。
