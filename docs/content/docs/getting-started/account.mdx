## 账号即门

群岛没有「先随便用用」的游客态。**不登录进不了岛**:

- 首次打开是整屏登录页:输入邮箱 → 收验证码 → 输入即完成登录或注册。**没有密码**。
- 登录成功后,本机会存一个本地令牌。之后每次启动,凭令牌直接解锁,不需要再收验证码。
- **登出 = 全局上锁**:整个应用立刻切回登录页。本地数据不会删。
- 令牌失效(换机、清数据、服务端吊销)时才需要重新收验证码。

<Callout type="warn" title="换机不是同步">
群岛的居民、记忆、聊天记录、工作区**只存在这台设备上**。在新电脑登录同一个账号,得到的是一座**新的空岛**,不是老岛的副本。需要带走的文件请自己从 `~/群岛/` 拷。
</Callout>

## 岛 = 账号 × 设备

这是群岛最容易被误解的一条:

| 场景 | 结果 |
| --- | --- |
| 同一个账号,两台电脑 | **两座岛**,数据互不相通 |
| 同一台电脑,两个账号 | **两座岛**,数据按账号目录物理隔离 |
| 同名居民在两座岛 | 完全独立的两个居民,记忆与技能不共享 |

所以「一台电脑,一座岛」。这套设计换来的是隐私上的确定性:数据不出本机,也就不存在「同步出错把 A 岛的记录写进 B 岛」。

## 设备列表

**设置 → 设备连接**里能看到:

- 当前账号的账号卡;
- 名下设备列表:哪台是本机、最后活跃时间、可直达岛务编辑;
- 退出登录入口。

设备识别用**设备指纹**:采集本机主板 UUID 派生出的盐化哈希随登录上报,**原始值不出本机**。好处是重装客户端或清掉数据后,服务端仍能认出这是原来那台设备,设备列表里不会重复出现两行。采集失败会自动退回旧的识别方式。

## 存量数据认领(0.7.x 及更早)

如果你从 0.7.x 之前的版本升级上来,旧数据是平铺在应用数据根目录里的,没有账号分区。首次登录时会出现**认领卡**:

1. 确认把这些数据归到当前账号;
2. 迁移是**四段式崩溃安全**的——中途断电或强制退出,下次启动会接着做,不会丢一半;
3. 居民、记忆、文件保持原样,只是换了目录归属。

选择「不认领」就保留原位,但新版本的岛不会读它。

## 登录不上怎么办

按顺序排查:

1. **收不到验证码**:先看垃圾邮件/拦截规则;国内邮箱偶尔延迟 1–2 分钟。连续点发送有冷却限制,等一会儿再试。
2. **提示验证码错误**:验证码是一次性的,且有时效。重新发一次,不要在旧邮件里反复试。
3. **启动直接进登录页**:说明本地令牌失效了(可能换过机、清过数据或被服务端吊销),正常登录一次即可。
4. 仍然不行,走[常见问题](/docs/help/faq)里的反馈渠道。
